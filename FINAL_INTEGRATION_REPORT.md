## Verification policy

Run `pytest backend/tests -q`, `cd frontend; npm run build`, and `python scripts/run_benchmark.py` before presenting a release. A benchmark report is valid only when generated by the current runner and identifies its baseline and configuration hashes.

## Model boundary

The thermal-loss scalar κ is a calibrated lumped parameter. Holdout improvement is not field qualification: it depends on the quality, timing, and representativeness of supplied observations. Deployment requires data validation, engineering review, and controlled operating procedures.
