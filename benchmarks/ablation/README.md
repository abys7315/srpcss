# Ablation Studies — SIH 26120

This directory defines ablation study protocols designed to scientifically assess the individual contribution of each system component:

1. **Physics Only**: Digital Twin physics without ML residual correction or confidence estimation.
2. **Physics + ML Residuals**: Evaluating accuracy improvements on non-linear viscous emulsion effects.
3. **Decoupled vs Joint Optimization**: Measuring the economic benefit of co-optimizing CSS soak with dynamic SRP pumping speed.
4. **Constraint Engine Impact**: Measuring the safety margin improvements when mechanical rod floating constraints are actively enforced.
