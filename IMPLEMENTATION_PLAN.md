## Machine Learning Models & Training Data Specifications

- [ ] **Model 1: Hybrid Residual Corrector (`HistGradientBoostingRegressor`)**
  - **Dataset:** `data/simulated/field_simulation_history.json` generated by `scripts/generate_synthetic_data.py`.
  - **Training Split:** Wells BGW-01 through BGW-06 under nominal physics ($\kappa=2.6, k=250\text{ mD}, s=0$).
  - **Test Split:** Held-out Wells BGW-07 through BGW-10 with perturbed physics ($\kappa=3.25, k=187.5\text{ mD}, s=+3.5$).
  - **Features:** `[day, temperature_c, viscosity_cp, flowing_bottomhole_pressure_bar, pump_fillage_pct]`.
  - **Expected Verification:** Nominal physics MAE $\approx 6.36\text{ BPD}$; hybrid model MAE $\approx 2.14\text{ BPD}$ ($66.4\%$ error reduction).
  - **Persistence:** Save champion model to `data/models/residual_corrector_champion.joblib`.
- [ ] **Model 2: Dynacard Classifier (`RandomForestClassifier`)**
  - **Dataset:** 500 physical dynamometer cards synthesized via `GibbsDynacardModel` in `twin/srp/dynacard.py` (100 per class: Normal, Rod Floating, Fluid Pound, Gas Interference, Overload).
  - **Features:** Normalized card area, minimum load ratio ($MPRL / W_{\text{sub}}$), load range ratio, downstroke inflection variance $\text{Var}(d^2 F/ds^2)$, centroid offset.
  - **Expected Verification:** Weighted F1-score $\ge 85\%$ on 100 noisy test cards.
- [ ] **Model 3: Reliability & Mechanical Failure Predictor**
  - **Provenance:** Relabeled `HEURISTIC_MECHANISTIC` (Basquin-Miner S-N fatigue + Goodman stress + impact shock).
  - **Training:** Automated right-censored Weibull MLE fitting routine estimating shape $\hat{\beta}$ and characteristic life $\hat{\eta}$ when user failure records are uploaded via CSV.
- [ ] **Model 4: Probabilistic Production Forecaster**
  - **Training:** Latin-Hypercube Sampling (LHS) across 200 parameter vectors ($k \sim \mathcal{N}$, $\kappa \sim \mathcal{U}$, $r_{\text{steam}} \sim \mathcal{N}$) to compute true empirical P10, P50, and P90 quantile envelopes.
